# Marketplace listing copy

**App name:** Scrutineer: Safety Release Gate

**Tagline (≤ 80 chars):** ISO 26262 traceability release gate for Jira, with evidence packs in Confluence

**Summary (≤ 250 chars):** See whether a safety-critical release is ready to ship. Scrutineer checks hazards, requirements, tests and results in Jira, flags verification made stale by changes, and publishes an evidence pack to Confluence.

## Highlights

1. **A go/no-go gate you can defend.** Ten deterministic ISO 26262 checks run on your real Jira issues and links, and every finding cites the exact issues.
2. **Change impact, automatically.** Edit a requirement and its tests are flagged suspect until they are re-run or an impact review records why they're still valid.
3. **Evidence in one click.** A Confluence evidence pack with a traceability matrix, result sources, sign-offs and a SHA-256 fingerprint.

## More details

- A Rovo agent explains findings and drafts missing tests. It always asks before creating anything.
- An MCP server lets external AI assistants check release readiness (read-only).
- A CI web trigger records test results from your pipeline or HIL bench.
- A workflow validator blocks closing a release while it is NO-GO.
- All data stays in your Jira, Confluence and Forge storage, and the app makes no outbound calls. (The CI web trigger only receives results.)
- A one-click demo project shows everything working in about a minute.

Scrutineer supports evidence gathering. It does not certify compliance.

**Category:** Project management / Testing & QA. **Products:** Jira, Confluence.
**Pricing:** Free.
**Privacy and security:** All data is stored on your Atlassian site: Jira issue and project properties, Confluence pages and Forge storage. The app makes no external network calls.
